# Module 10 — Standards and assessment: the activity

AMLUCS 2026 — Standards and assessment. A short activity, no new scan and no long
conformity-assessment lab.

## The task (2 minutes, then a 1-minute discussion)

Choose one finding from your existing work. If you do not have one, use the recorded
example shown by the instructor. In two minutes, identify one missing item of evidence
and explain why it matters. For example, you might need the tested configuration, a
trusted tool record, or a check that an allowed task still works. Add a sentence to your
existing notes and be ready to discuss it.

## Interpretation

Missing evidence can limit a conclusion, but it does not erase a failure already
supported by other evidence. Say which question the missing item would help answer. This
exercise improves one finding; it does not complete a conformity assessment.

## Optional further work

Mapping the finding to a specific standard provision, and populating a full evidence-field
table, is useful take-home work when the detailed standards reference is available. It is
not part of this short activity.
